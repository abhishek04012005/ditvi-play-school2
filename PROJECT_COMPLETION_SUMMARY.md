## 🚀 Usage

### For End Users
```
1. Open AR Books section
2. Select a book to read
3. Click Print button (🖨️)
4. View print preview
5. Click Print & configure settings
6. Print physical book
```

### For Developers
```typescript
// Import and use components
import ARBookPrintTemplate from '@/components/ar/arBookPrintTemplate';
import ARBookPrintPreview from '@/components/ar/arBookPrintPreview';

// Use in custom pages
<ARBookPrintTemplate book={book} />
<ARBookPrintPreview bookId="book-001" />

// Access routes
/ar-books/print
/ar-books/{bookId}/print
```
