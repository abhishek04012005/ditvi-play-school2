# 🖨️ Print Features - Quick Reference

## Three Ways to Print

### 1️⃣ Admission PDF - Print Preview
**Location:** Admission form details page
**Button:** 🖨️ Print
**Action:** Opens print dialog with preview
**Output:** Can print or save as PDF
**Devices:** Works on phone, tablet, desktop

### 2️⃣ Admission PDF - Download PDF
**Location:** Admission form details page
**Button:** 📥 Download PDF
**Action:** Downloads A4-sized PDF directly
**Output:** File saved as `Admission_AD[NUMBER].pdf`
**Devices:** Works on phone, tablet, desktop

### 3️⃣ Dashboard - Print Full Dashboard
**Location:** Admin Dashboard → Admissions page
**Action:** Press `Ctrl+P` (Windows) or `Cmd+P` (Mac)
**Output:** Prints/saves entire dashboard
**View:** Desktop layout with status cards + table
**Devices:** Works on phone, tablet, desktop

## Mobile Print Instructions

### iPhone/iPad (Safari)
```
1. Open admission form
2. Tap Share button (⬆️)
3. Scroll down → "Print"
4. Select printer or "Save PDF"
5. Tap "Print" / "Save"
```

### Android (Chrome)
```
1. Open admission form
2. Tap Menu (⋯)
3. Select "Print"
4. Choose "Save as PDF" or printer
5. Tap "Save" / "Print"
```

### Dashboard Print (Mobile)
```
1. Open Admin Dashboard
2. Tap Menu (⋯) → Print
3. Print dialog opens
4. Select printer or "Save to PDF"
5. Note: Dashboard prints in WEBSITE VIEW
```

## Print Settings Recommendations

### Margins
- Default: Minimal (saves paper)
- If cut off: Try Normal

### Paper Size
- A4 (210 × 297mm) - Standard
- Letter (8.5 × 11") - USA

### Scale
- 100% - Best for accuracy
- 75-90% - Fits more on page
- 110%+ - Larger text

### Background Graphics
- ON - Print colors and styling
- OFF - Black & white only

## Common Issues & Quick Fixes

| Issue | Quick Fix |
|-------|-----------|
| Cut off content | Set margins to Minimal |
| Text too small | Zoom 110-120% in preview |
| Colors missing | Enable "Background graphics" |
| Mobile layout printing | Clear cache, use Chrome |
| Multiple blank pages | Reduce margins, disable headers |
| Slow PDF generation | Wait for images to load |

## Frequently Asked Questions

**Q: Can I print multiple admissions at once?**
A: Not directly, but dashboard prints all visible admissions in one page.

**Q: How do I get the best quality PDF?**
A: Use Chrome, set zoom 100%, select "Save as PDF", enable background graphics.

**Q: Can I edit the PDF after downloading?**
A: Yes, use any PDF editor (Adobe, Preview, online tools).

**Q: Is there a watermark option?**
A: Not yet, but can be added as future feature.

**Q: How do I print in color?**
A: Enable "Print background graphics" in print settings.

**Q: Can I print without action buttons?**
A: Buttons hide automatically when printing/saving.

**Q: Works on iPad?**
A: Yes, use Safari print or AirPrint to printer.

**Q: Mobile layout on print?**
A: No, prints WEBSITE VIEW (full desktop layout) on all devices.
