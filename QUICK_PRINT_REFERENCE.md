# 🖨️ Quick Print Guide - Admission Dashboard

## 📱 Print from Phone
1. Tap **Menu** (⋯) or **Share**
2. Select **Print** or **Print to PDF**
3. Choose printer or save location
4. ✅ Dashboard displays in **desktop layout**
5. Print!

## 🖥️ Print from Desktop
1. Press **Ctrl+P** (Windows) or **Cmd+P** (Mac)
2. Select your printer
3. ✅ Print preview shows **desktop layout**
4. Click **Print**

## 💾 Save as PDF (Recommended)
1. Open print dialog (Ctrl+P or Cmd+P)
2. Select **Save as PDF** instead of printer
3. Choose location to save
4. ✅ PDF will have **desktop layout** preserved
5. Perfect for sharing and archiving

## ✅ What You'll See

- **Status cards** in 4-column grid
- **Admission table** with all columns visible
- **White background** with black text
- **Full-width** layout (not mobile)
- **Clean printing** (no buttons, modals, or navigation)

## ⚙️ Recommended Print Settings

| Setting | Recommended |
|---------|------------|
| **Paper Size** | A4 |
| **Orientation** | Portrait |
| **Margins** | Minimal |
| **Background Graphics** | ON |
| **Zoom** | 100% |

---

## 🚫 What's Hidden When Printing

- ❌ Modals and dialogs
- ❌ Buttons
- ❌ Navigation bars
- ❌ Animations
- ❌ Shadows
- ❌ Gradients

---

## ❓ Troubleshooting

| Problem | Solution |
|---------|----------|
| Text too small | Increase zoom to 110-120% |
| Content cut off | Set margins to Minimal |
| Colors not printing | Enable "Print background graphics" |
| Mobile layout appears | Clear cache and try again |
